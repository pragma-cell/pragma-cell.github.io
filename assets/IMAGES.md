## Résumé des priorités de remplacement

| Priorité | Fichier | Raison |
|----------|---------|--------|
| Haute | `logo.svg` + `favicon.svg` | Identité de marque — bulle de chat trop générique, sans lien avec Pragma IT |
| Haute | `hero-illustration.svg` | Illustration "clipart tech" datée, peu différenciante |
| Haute | `tool.svg`, `growth.svg`, `shield.svg` | Icônes de philosophie trop génériques |
| Haute | `implementation.svg`, `training.svg` | Métaphores visuelles peu précises |
| Moyenne | `audit.svg` | Correct mais banal |
| Moyenne | `business.svg` | Métaphore de la carte bancaire inadaptée pour un n° de TVA |
| Basse | `phone.svg`, `email.svg`, `location.svg` | Standards universellement reconnus, pas prioritaires |
| Basse | `linkedin.svg`, `github.svg` | Logos officiels, à conserver ou remplacer par versions officielles |
| Variable | `team-*.jpg`, `og-image.jpg` | Dépend du contenu réel souhaité |
